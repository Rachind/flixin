# FlixIn — Android-приложение

Игра лежит в папке `www/` (`index.html` + `css/style.css` + скрипты в `js/`) — это бывший
единый файл `flixin.html`, разбитый на части без изменения логики и обёрнутый через
[Capacitor](https://capacitorjs.com/) в нативный Android-проект (папка `android/`).
Весь код игры, сохранения (`localStorage`) и логика работают точно так же, как в браузере.

Собрать `.apk` прямо в этой песочнице нельзя: здесь нет доступа к серверам Google
(`dl.google.com`) и Maven, откуда Gradle скачивает Android SDK/плагины. Это ограничение
самой среды, а не проекта — сам проект полностью готов к сборке. Есть два способа
получить готовый файл `.apk`, не устанавливая ничего лишнего:

## Способ 1 — GitHub Actions (ничего не ставить на компьютер)

Один раз нужно создать постоянный ключ подписи. Без него каждая сборка подписана
по-разному, Android не ставит её поверх старой, и прогресс теряется.

1. Создай ключ (нужна Java, команда `keytool`):
   ```bash
   keytool -genkeypair -v -keystore flixin.jks -alias flixin -keyalg RSA -keysize 2048 -validity 10000
   base64 -w0 flixin.jks > flixin.jks.b64
   ```
   Сохрани `flixin.jks` и пароли в надёжном месте и **не коммить** их. Если ключ потеряется,
   обновления перестанут ставиться поверх.
2. В репозитории открой **Settings → Secrets and variables → Actions** и добавь секреты:
   - `ANDROID_KEYSTORE_BASE64` — содержимое `flixin.jks.b64`;
   - `ANDROID_KEYSTORE_PASSWORD` — пароль хранилища;
   - `ANDROID_KEY_ALIAS` — `flixin`;
   - `ANDROID_KEY_PASSWORD` — пароль ключа (обычно тот же).
3. Запушь изменения в `main`. Сборка запустится сама и опубликует **Release** `build-N`
   с файлом `flixin.apk`.
4. Обновление с телефона: **Настройки → Версия → Проверить → Скачать**, затем открой
   скачанный файл и нажми «Обновить». Корабли и кредиты сохранятся.

## Способ 2 — Android Studio (на своём компьютере)

1. Установи [Android Studio](https://developer.android.com/studio) (она сама подтянет
   нужный SDK при первом запуске).
2. Открой в ней папку `android/` из этого проекта как существующий проект.
3. Дождись синхронизации Gradle (идёт автоматически, нужен интернет).
4. **Build → Build Bundle(s) / APK(s) → Build APK(s)** — получишь `.apk` в
   `android/app/build/outputs/apk/debug/`.
   Или сразу **Run ▶** — установит и запустит игру на подключённом телефоне/эмуляторе.

## Что дальше

- Иконка приложения сейчас стандартная (заглушка Capacitor) — я могу подставить
  пиксельный логотип FlixIn отдельным шагом.
- Если что-то в игре поменяется — правь файлы в `www/` (разметка — `index.html`, стили —
  `css/style.css`, код — `js/*.js`), выполни `npx cap sync android` и пересобери
  (или запушь заново на GitHub — Action пересоберёт сама). Для быстрой проверки достаточно
  открыть `www/index.html` в браузере.
