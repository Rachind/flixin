# FlixIn — Android-приложение

Игра (`www/index.html`) не переписана — это тот же файл `flixin.html`, обёрнутый через
[Capacitor](https://capacitorjs.com/) в нативный Android-проект (папка `android/`).
Весь код игры, сохранения (`localStorage`) и логика работают точно так же, как в браузере.

Собрать `.apk` прямо в этой песочнице нельзя: здесь нет доступа к серверам Google
(`dl.google.com`) и Maven, откуда Gradle скачивает Android SDK/плагины. Это ограничение
самой среды, а не проекта — сам проект полностью готов к сборке. Есть два способа
получить готовый файл `.apk`, не устанавливая ничего лишнего:

## Способ 1 — GitHub Actions (ничего не ставить на компьютер)

1. Создай новый репозиторий на GitHub и залей туда содержимое этой папки целиком
   (там уже лежит `.github/workflows/build-apk.yml`).
2. Зайди во вкладку **Actions** репозитория — сборка запустится сама.
   Если не запустилась — нажми **Run workflow** вручную.
3. Через 3-5 минут в результатах сборки (Artifacts) появится файл
   **flixin-debug-apk** — это и есть `.apk`. Скачай и установи на телефон
   (Android спросит разрешение на установку из «неизвестных источников» — это нормально
   для файла не из Google Play).

## Способ 2 — Android Studio (на своём компьютере)

1. Установи [Android Studio](https://developer.android.com/studio) (она сама подтянет
   нужный SDK при первом запуске).
2. Открой в ней папку `android/` из этого проекта как существующий проект.
3. Дождись синхронизации Gradle (идёт автоматически, нужен интернет).
4. **Build → Build Bundle(s) / APK(s) → Build APK(s)** — получишь `.apk` в
   `android/app/build/outputs/apk/debug/`.
   Или сразу **Run ▶** — установит и запустит игру на подключённом телефоне/эмуляторе.

## Что дальше

- Иконка приложения сейчас стандартная (заглушка Capacitor) — я могу подставить
  пиксельный логотип FlixIn отдельным шагом.
- Это debug-сборка (для себя/установки вручную). Для публикации в Google Play
  потребуется ещё подписать `.apk`/`.aab` release-ключом — отдельная тема, если
  дойдёт до этого.
- Если что-то в игре поменяется — просто скопируй новый `flixin.html` в `www/index.html`
  и пересобери (или запушь заново на GitHub — Action пересоберёт сама).
